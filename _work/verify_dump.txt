SUMMARY: 관점은 레벨 경계 검증이다. 214개 전부를 경계표에 대고 확인했다. 원문으로는 기동 순서(설치 기준서 docx, 단독 실행 pptx), v04 목차(Report 10.1~10.17, Layout 13.1~13.3), setup 가이드 4.4/4.5와 5.7을 직접 확인했다.

[확정 op 9건]
① L3b-12 → L3a: Rose 조작이 없고, 이력·설정을 대조해 원인을 특정하는 일이라 L3-a다.
② AUX-18 L3 → L2: 절차대로 하는 시뮬 환경 구성이다. 같은 절차를 L1-50은 L1로 두고 있다.
③ AUX-17 → L3a-08 병합: 근거와 절차가 같다.
④ L2c-20 → L2b-02 병합: IIS 점검은 L2-c 정의 밖이고, 같은 현상을 지목하는 역량이 두 곳에 있었다.
⑤ L1-31: 목표에서 L2-c 역량을 빼고, L1 조작 항목이 없던 CommHistory·UIHistory·FailOverHistory를 넣었다.
⑥ L2a-16: L1-21과 겹치는 MTL 5조건 판독을 뺐다.
⑦ L3a-24: 목표가 L1-11과 같은 행위뿐이어서 본문에 있던 L3 요소로 바꿨다.
⑧ L2b-04·L3b-13: 기동 순서 자료충돌 flag.
⑨ AUX-04: 제목에서 '설정'을 뺐다.
적용 후: L1 50 / L2a 18 / L2b 32 / L2c 20 / L3a 39 / L3b 13 / L3c 12 / AUX 28 = 212.

[10개 탭 L1 점검]
Layout 탭은 실질 L1이 0개다. L1-43(탭:Layout)의 내용은 메인화면 ⑤layout·⑥찾기·System>Home 결과색이고, Layout 메뉴(v04 13.1 Run/13.2 Check/13.3 Setting, MXA MapLoad)가 아니다. 정의가 Run/Check/Setting을 L2-a로, MapLoad를 L3-c로 묶어서 생긴 결과라 op 대신 발주자 결정을 요청한다.
- (a) 그대로 수용한다.
- (b) 맵을 바꾸지 않는 Layout>Setting(UI 표시 크기)이나 'Layout>Check 실행·Message 목록 읽기'를 L1로 분리한다.
나머지 9개 탭에는 L1이 있다. 다만 실제 View 메뉴를 다루는 L1은 L1-04뿐이고, Help의 실제 화면 항목은 2개다(L1-48은 용어집). 탭 내부 공백은 다음과 같다.
- Object>Segment·Safety는 L2-a에만 있다(정의상 수용 가능).
- System>AltTransfer(setup 가이드 5.10)는 등록 조작 L1이 없다.

[경계 의심: op 미제출, 판단 요청]
- L3b-01: 콘솔 로그인과 4요소 상태 읽기는 경계표상 '상태값 읽기 = L1~L2'다. L1-06(ALIVE), L1-21(5상태 판정)과 기준이 어긋난다. L2로 내리거나 'L3-b 선행요건'으로 명시해야 한다.
- L3b-11: 경로 확인과 Standby 접근 시험은 점검(L2)이고 AUX-09와 짝을 이룬다. 'Failover 비정상 원인 특정'으로 목표를 바꾸지 않으면 레벨이 과하다.
- L3b-04: SECS 복구 판정이 L3a-34와 같은 예시로 중복된다. L3-b에만 있는 내용은 VIP 접속과 FailOverHistory 확인뿐이다.
- L3c-12: 조작을 도구 내부 / 실반영으로 분류하는 일은 구조 이해(L2-b) 성격이다.
- L2a-11: 목표는 MaxVehicleCount 지정인데 flags는 'Cluster 수치 튜닝 = L3-a'라고 적혀 있다. '초기값 입력(L2-a)과 현상 해결 조정(L3-a)'을 가르는 문구가 필요하다. L2a-12 Weight와 L2a-14 DisableBlock(안전 영향)도 같은 경계에 걸린다.
- L2a-17: L2-a 목표 안에 Sub Command(차량 이동)라는 L1 조작이 섞여 있다.
- AUX-06: Parameter 조정이라 L3-a(L3a-38과 같은 성격)에 맞는다.
- AUX 안에서 기준이 일관되지 않다. 기준값대로 하는 설정이 AUX-13은 L1, AUX-15는 L2, AUX-22·23은 L3다. 절차대로 하는 AUX-10은 L3인데 AUX-09는 L2다.
- L2b-04: 목표의 '어느 조건이 전이를 막는지'에 진단 뉘앙스가 있다. 채점은 '파라미터 관계 설명'으로 한정해야 한다.

[정의와 어긋난 주석: 텍스트라 op 대상 아님]

- L1-15·L1-27 'CycleMove 경로 구성은 L2-a로 분리': L2-a에 해당 항목이 없다.
- L2b-01·L1-46 'RCPGT 외 UI 없음': L1-49·L1-50(MCS_IF 화면), L3c-09(Core>System 탭>MabLoad), L2c-19(CORE 상태 표시)와 충돌한다.
