1. 메인 화면 (2) 메뉴


 ① File
    File
      New : 새로운 사이트를 생성한다.
      Open : 생성된 사이트를 읽어 들인다.
    Save
      Save : 수정된 사이트를 저장한다.
      Save As : 작업중인 사이트의 복사본을 생성한다.


 ② Edit
    Object
      Select : 디자인 작업 창에서 객체의 선택, 줌, 이동(마우스 왼쪽버튼 클릭)을 한다.
      Segment : 디자인 작업 창에서 세그먼트를 작도한다.
      Point : 디자인 작업창에서 마우스 클릭 위치에 포인트를 생성한다.
    Design
      차량, 작도 종류, 세그먼트 템플릿을 선택한다.
    Lock
      디자인 작업차의 작업을 잠근다.
    Redo/Undo
      Undo : 실행을 취소한다.
      Redo : 직전 작업을 다시 실행한다.


 ③ View
    Drawing
      [Point ID] : 디자인 작업창에 포인트 아이디의 화면 출력 여부를 선택한다.
      [Segment ID] : 디자인 작업창에 세그먼트 아이디의 화면 출력 여부를 선택한다.
      [Boundary] : 디자인 작업창에 세그먼트의 영역 바운더리에 대한 화면 출력 여부를
           선택한다.
      [Swept] : 디자인 작업창에 차량의 궤도의 표시 여부를 선택한다.
    Drawing Info
      Point : 디자인 작업 시 선택된 포인트 정보의 화면 출력 여부를 선택한다.
      Segment : 디자인 작업 시 선택된 포인트 정보의 화면 출력 여부를 선택한다.

④ Setup
   Layout
    [Auto-Blocking Configuration] : 오토블로킹 계산 파라메터를 설정한다.
    [Drawing Boundary] : 디자인 작업 영역을 설정한다.
    [Drawing Configuration] : 배경 캐드 파일에서 레이어의 화면 출력
                         여부를 설정한다.
    [ID View Properties] : 포인트, 세그먼트 아이디의 화면 출력 여부를 선택한다.
    [Drawing] : 사이트 정보 및 화면 표시 색상 값을 설정한다.
    [Object View Properties] : 디자인 작업창에 세그먼트 템플릿과 객체의 출력
                         여부를 선택한다.



⑤ Tool
   Swept
    Show All Swept : 세그먼트를 지나는 차량 궤도를 디자인 창에 출력한다.
    Hide All Swept : 세그먼트를 지나는 차량의 궤도를 디자인 창에서 숨긴다.
   Direction
    Show All Direction : 세그먼트의 진행 방향을 디자인 창에 출력한다.
    Hide All Direction: 세그먼트의 진행 방향을 디자인 창에서 숨긴다.


⑥ Window
   Documents
    Windows : 디자인 작업 창에 열려 있는 사이트 목록을 선택한다.

4. 디자인 작업 (4.1) 세그먼트 작도 : 기본 작도




 ① 메뉴 바에서 Edit > Object > Segment를 선택한다.
 ② 시작 위치에 마우스의 왼쪽 버튼을 클릭 후 진행 방향을 정한 후 클릭을 해제한다.
 ③ 마우스를 다음 위치로 이동 후 클릭을 해제한다.
 ④ 작도가 마치면 마우스 오른쪽 버튼이나 더블 클릭으로 마친다.
 ⑤ 작도 시 배경 이동은 마우스 오른쪽 버튼 클릭 후 이동한다.

4. 디자인 작업 (4.2) 객체 선택


 ① 마우스를 클릭하여 세그먼트 및 포인트를 선택한다.

 ② {Ctrl} 키를 누른 채 마우스를 클릭하면 선택 항목에 추가하거나 해제할 수 있다.

 ③ {Shift} 키를 누른 채 마우스를 클릭 이동하여 선택 영역의 객체를 선택한다.
    (영역 밖의 선택 항목은 해제된다)

 ④ {Ctrl} {Shift} 키를 동시에 누른 채 마우스 클릭 이동하여 선택 영역의 객체를
    선택 항목에 추가한다.

 ⑤ {Esc} 키를 눌러 모든 선택 항목을 해제한다.




                                                       19
4. 디자인 작업 (4.3) 세그먼트 작도 : 키보드 조합




 ① 세그먼트의 진행 각도는 45도 씩 시계 방향 혹은 반시계 방향으로 회전한다.
 ② 키보드의 {Alt} 키를 누른 채로 마우스를 이동 하면 미세 각도로 회전 할 수 있다.
 ③ 작업 진행에 대한 취소는 {ESC} 키를 클릭한다. (한 단계씩 취소 됨)
 ④ 처음에 {Shift} 키를 누른 상태에 서 마우스를 클릭하면 직선 세그먼트를 생성한다.
    (종점 포인트를 그린 색으로 표시).
