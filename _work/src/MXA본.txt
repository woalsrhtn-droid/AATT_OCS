프로그램 구성도

RCP는 'CORE‘, ‘RCP GT’, ‘PLC Driver’, ‘MCS_IF’, ‘DataBase’ Program들로 구성된다. 
RCP GT를 제외한 프로그램들은 사용자 Interface가 없고, 내부적으로 구동되고 있는 프로그램이므로 본 매뉴얼에서는 RCP GT에 대한 내용만을 다루고있다. 
 
화면 구성( 기본 구성 요소)
전체화면구성(기본화면)


1. 사용자 정보 및 로그인
2. 메뉴탭 : View, System, Object, Transfer, Report, Statics, Window, Layout, PlayBack, Help으로 구성되어 있다. 
3. OrderList : Vehicle 차량의 명령 상태 확인
4. 화면의 확대, 축소 조작 (마우스의 wheel scroll시 화면의 확대, 축소도 가능)
5. Point, Segment, Vehicle, Station, CassetteID 찾기 : ex) Point번호나 segment 번호 입력 후 Enter, 해당 숫자의 위치가 크게 표시되며, 찾아가는 기능이 있다.
6. 화면 layout : Point와 Segment, 차량 움직임 등을 알 수 있다.
7. ErrorList : Vehicle 차량의 Error
8. Core, PLC, Host : 연결된 상태인 경우 빨간 불(Core), 초록 불(Host)이 깜빡인다.

둘의 CSTID가 다른 경우 오더를 삭제함
- CleanStatus : 차량이 이적재할 화물을 Normal/Clean/Dirty 중에 하나 지정함. 
ex) Clean 으로 지정된 차량은 Clean한 화물만 이/적재 할 수 있다

CIM
Computer Integrated Manufacturing의 약어로 컴퓨터에 의한 통합적 
생산시스템을 뜻한다. 즉 컴퓨터를 이용, 기술개발·설계·생산·판매에

DATABASE
자료 기지 또는 자료틀, 보통 DB라고 약칭한다. 동시에 복수의 적용 
업무를 지원할 수 있도록 복수 이용자의 요구에 호응해서 데이터를 
받아들이고 저장, 공급하기 위해 일정한 구조에 따라서 편성된 
데이터의 집합

FDC
Fault Detection & Classification의 약어로 장비를 운영함에 있어서 
여러 문제점 및 특이 현상이 발생할 수 있고 
이런 문제를 최소화 하기 위하여 여러 문제점을 Data 관점에서 해석하여 
문제의 원인을 탐색하고 해당 원인이 나타날 조짐이 보일 때 미리 
알려 주는 시스템.

FTP
File Transfer Protocol 의 약어로 인터넷을 통해 한 컴퓨터에서 다른 
컴퓨터로 파일을 전송할 수 있도록 하는 방법과, 그런 프로그램을 모두 
일컫는 말.

UI FontColor 및 Background 색상 설정 기능

인터넷 네트워크에 접속되어 다른 인터넷 호스트와 통신 할 수 있는 
컴퓨터를 말한다. 호스트는 패킷의 원천이기도 하고 목적지이기도 하다.
호스트는 클라이언트이기도 하고 서버이기도 하다. 인터넷 네트워크에서
호스트는 인터넷 이름과 인터넷 주소에 의해 식별된다.

Internet Protocol의 약어로 인터넷상의 한 컴퓨터에서 다른 컴퓨터로 데이터를 보내는 데 사용되는 프로토콜.

Material Control System의 약어로 최적경로를 선정하여 최단시간 내에

Mantech Continuous Cluster Server의 약어로 Windows, Linux 환경에서 시스템 장애 및 서비스 장애 발생시 빠른 서비스 전이를 통해 연속적인 비즈니스 환경을 제공하는 고 가용성 이중화 솔루션 입니다
MCCS 는 시스템 정전 및 어플리케이션 무응답, DISK I/O 등에 대한 실시간 감지를 제공하며, 자동화된 빠른 서비스 전이를 제공합니다
