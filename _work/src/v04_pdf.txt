1. 개요

 OCS(OHT Control System)는 OHT 를 운영하는 시스템으로 반송 작업을 관리하고,
효율적으로 Vehicle 을 운영하여 최고의 반송 효율을 실현하는 것을 목적으로 한다. 본
문서는 OCS 사용자 매뉴얼로서 OCS 운영 담당자는 효율적인 시스템 운영을 위해
OCS 사용 전 본 MANUAL 을 반드시 숙지하여야 한다.

4) Cluster Info




 - Cluster ID : Cluster Number
 - Name : Cluster Name
 - MaxVehicleConut : Cluster 내로 들어올 수 있는 총 Vehicle 대수
 - MaxVehicleReleaseCount : 특정 Cluster 투입 제한을 해제하는 Vehicle Count 수
 - Unuse : Cluster 의 기능을 Use/Unuse 시킨다
 - DestOtherCluster : 특정 Cluster 내에 있는 Vehicle 이 밀어내기로 이동될 Cluster ID 를
   직접 입력(‘0’으로 설정하면 자동 검색)
 - DestOtherPoint : 특정 Cluster 내에 있는 Vehicle 이 밀어내기로 이동 될 위치 Point 를
   직접 입력('0'으로 설정하면 자동검색)
 - ShouldFindOtherClusterHome : 특정 Cluster 내에 있는 Vehicle 이 밀어내기로 인해
   대기 장소를 찾을 때, 현재 OHS 가 속한 Cluster 이외에 다른 Cluster 의 Home
   Point 를 검색
 - ShouldFindOtherClusterOrde : 특정 Cluster 내에 Order 가 발생하는 경우, 해당
   Cluster 내에 있는 Vehicle 이 Order 할당 우선순위가 된다.
 - MaxVehicleLowCount : CLUSTER 차량 배출시작 기준(차량 수>MaxVehicleLowCount)
 - MaxVehicleHighCount : CLUSTER 내부 Order 할당 금지 기준
   (차량 수 > MaxVehicleHighCount)
 - Use Member Vehicle : Control Vehicle Count 에 대해서 특정 호기에만 적용 시키기
   위하여 사용
 - ListPoint : 해당 Cluster 에 등록된 Point List
 - Etc. 기타 : Spare

- 실행 : 차량에서 명령을 실행한 시간

- From 완료 : Station 에서 적재를 완료한 시간
- To 도착 : 차량이 ToStation 에 도착한 시간

- 마지막할당->실행 : 마지막할당 시간부터 차량이 실행까지 시간
- 실행->From 도착 : 차량이 실행한 시간부터 From Station 에 도착까지 걸린 시간
- From 도착->From 완료 : From Station 에 도착 후 적재를 완료까지 걸린 시간
- From 완료->To 도착 : From Station 에서 적재 완료 후 ToStation 도착까지 걸린 시간
- To 도착->To 완료 : ToStation 도착부터 목적지에 Cassette 를 내려놓기까지 걸린 시간
- 생성->To 완료 : 명령 생성 후 목적지에 Cassette 를 내려놓기까지 걸린 시간
- 마지막할당->To 완료 : 마지막할당 시간부터 목적지에 Cassette 를 내려놓기까지 걸린
시간
- 실행->To 완료 : 차량이 명령을 실행한 시간부터 목적지에 Cassette 를 내려놓기까지
걸린 시간
- Completed : 반송 완료 유무
- Deleted : 프로그램에서 명령 삭제 유무
