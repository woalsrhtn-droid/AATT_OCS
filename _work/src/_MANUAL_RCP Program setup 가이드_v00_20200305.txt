7) Tag 등록
A. 목적 : Plc Unit에서 오는 정보를 System에 적용
B. 방법 : Object Tag 등록 > PLCTag 등록 > ErrorTag 등록

Object 마다 적용 할수 있는 Tag가 다르다
제어측에서 전달 받은 PLC 주소값을 데이터 타입에 맞추어 등록
기본적으로 하기와 같이 맞춘다
Object : Item Name = PlcTag : TagName
Objcet : Item Number = PlcTag : TagNumber
PlcTag : Name = ErrorTag : ErrType
PlcTag : Value = ErrorTag : ErrEvent

Not Define 알람이 올라오면 확인하여 ErrorTag 추가 및 수정
RCP에서 자체적으로 올라오는 알람은 초기 셋업 진행하면 자동으로 들어가 있다.


8) CPS 등록 및 범위 지정

CPS Failover시 해당 부분을 UI에서 표기 가능
CPS Error시 해당 범위 차량 이동 및 진입 통제 가능
그룹화하지 않으면 Failover시 라인 다운 현상이 생길 수 있다.

- Switch independent : Teaming에 스위치를 가입시킬 필요가 없는 설정, teaming에 설정한 랜포트를 다른 스위치에 연결해도 무방

- Address Hash : 일반적으로 팀의 모든 NIC에서 트래픽의 로드 균형을 조정
