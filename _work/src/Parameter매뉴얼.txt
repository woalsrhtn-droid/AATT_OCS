1. DataBase Param

  1.1. DBBackupFolder

 항목   1. DataBaseParam -> 1.1 DBBackupFolder
 내용   Database Backup 경로(Ex : D:\Backup)
 목적   SQL Server 의 Database Backup 경로를 설정한다.




                          1

 사용
 예시




      Ex ) Database Backup 경로 - D:\DatabaseBackup\
      ① D 드라이브 -> DatabaseBackup 폴더 -> 날짜 및 시간 별로 파일 생성
      ※ 알집에는 aspnetdb.BAK / Host.BAK / OrderList.BAK / RCP.BAK / Rundata.BAK / Winlay.BAK /
 참고
      WinlayUpdate.BAK 이 압축되어 있다.



  1.2. DBBackupFolder2

 항목   1. DataBaseParam -> 1.2 DBBackupFolder2
 내용   Database Backup2 경로(Ex : D:\Backup2)
      여분의 백업 경로로, SQL Server 의 두번째 Database Backup 경로를 설정한다.
 목적
      (DBBackupFolder Param 의 경로와는 다른 경로로 지정해야 한다.)




                          1

 사용
 예시



      Ex ) Database Backup 경로 - D:\DatabaseBackup2\
      ① D 드라이브 -> DatabaseBackup2 폴더 -> 날짜 및 시간 별로 파일 생성
      ※ 알집에는 aspnetdb.BAK / Host.BAK / OrderList.BAK / RCP.BAK / Rundata.BAK / Winlay.BAK /

      WinlayUpdate.BAK 이 압축되어 있다.

항목   1. DataBaseParam -> 1.3 DBBackupPeriod
내용   Database Backup 파일 저장 기한
목적   Database Backup 파일의 Save 기한을 정해 입력된 기한을 넘을 경우 자동 삭제를 한다.
사용   ① Value 에 ‘1’ 입력 시
예시    - 1 일(24 시간) + 23 시간 59 분 59 초까지 저장된다.
참고



1.4. DBBackupInterval

항목   1. DataBaseParam -> 1.4 DBBackupInterval
내용   Database Backup 실행 주기 (0=사용 안함)
목적   Database 의 Backup 실행 주기를 설정한다.
사용   ① Value 에 ‘1’ 입력 시
예시    - 1 시간마다 Database Backup 을 실행한다.
참고   ※ 실행 주기를 짧게 설정하게 되면 해당 드라이브의 저장용량이 부족할 수 있다.
